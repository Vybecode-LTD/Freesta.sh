Freesta.sh: three directions

The same search screen rendered three ways, with real public-domain results. Each direction also styles one API-key row so you can see the "where to get this key" link under the input. Every direction ships in dark and light; these show each one's primary theme. Pick one by eye, or name the parts you want to mix.

A

Provenance

A museum registrar's light table, run with an instrument's precision. Results are matted specimens; catalog data is set in mono; titles in a book serif.

Signature
The clearance rail: five segments under every result, one per use case (Reference, Demo, Client, Bundled, Merch), so you see "fine for a demo, not for a template" without opening it.
Fuses
Archival paper × instrument hairlines × one ember accent

Aperture

Search as a lens. Twenty sources open like an iris as their answers arrive; cleared work glows from inside cold optical glass.

Signature
The source aperture: a ring of tick marks, one per source, that lights as each source reports, with a response-time bar per source beneath the search. The federated search becomes visible.

Index
