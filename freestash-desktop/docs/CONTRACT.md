# API contract with the Freestash engine

The desktop app is a client of the Freestash HTTP API (`freestash/src/freestash/api/app.py`). C# models in
`src/Freestash.Client/Models.cs` mirror `freestash/src/freestash/models.py` (snake_case JSON, lowercase enum strings).

| Endpoint | Used by |
|---|---|
| `GET /api/health` | EngineHost status pill |
| `GET /api/search/stream` (SSE: `batch` per provider, then `done`) | Search |
| `GET /api/assets/{uid}?use=` | Detail panel (renditions + all five verdicts + HTML credit) |
| `POST /api/license/check` | License check |
| `GET/POST/DELETE /api/collections…` | Collections |
| `GET /api/ledger`, `/api/ledger/projects`, `/api/ledger/export`, `POST /api/ledger` | Ledger + download recording |
| `GET /api/providers`, `/api/pd-cutoff` | Sources, License check |

## Keeping it in sync

`tests/Freestash.Client.Tests/Samples/` were generated by the real API (FastAPI TestClient fed by recorded provider
fixtures). When `models.py` changes, regenerate them from the freestash repo and run the contract tests:

```python
# in the freestash repo, with respx installed
from fastapi.testclient import TestClient
from freestash.api.app import app
# ...mock providers with tests/fixtures, then save /api/search/stream, /api/assets/{uid}, /api/providers,
# /api/license/check, /api/collections/{id}/items, /api/ledger, /api/health responses into Samples/
```
